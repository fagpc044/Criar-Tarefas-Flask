# 📝 Lista de Tarefas com Flask

Projeto simples desenvolvido com **Python e Flask** para praticar os conceitos básicos de desenvolvimento web com Flask.

A aplicação permite **criar e visualizar tarefas**, utilizando uma lista Python para armazenar os dados temporariamente.

> 🚧 Projeto desenvolvido para fins de estudo. Ainda não utiliza banco de dados.

---

## 🚀 Funcionalidades

- ✅ Criar tarefas
- ✅ Adicionar descrição às tarefas
- ✅ Visualizar tarefas cadastradas
- ✅ Navegar entre a página inicial e a página de visualização
- ❌ Excluir tarefas — próximo passo
- ❌ Banco de dados — será implementado posteriormente

---

- Python
- Flask
